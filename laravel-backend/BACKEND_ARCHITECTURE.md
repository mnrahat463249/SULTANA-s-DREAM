# AURA Atelier & Sultana's Dream — Complete E-Commerce Backend Architecture

এই ডকুমেন্টে একটি পূর্ণাঙ্গ, এন্টারপ্রাইজ-গ্রেড লাক্সারি ই-কমার্স প্ল্যাটফর্মের ব্যাকএন্ডে **কী কী মডিউল থাকে**, সেগুলো **কোথায় সংরক্ষিত আছে** এবং **কীভাবে ফ্রন্টএন্ডের সাথে কাজ করে** তা বিস্তারিতভাবে বর্ণনা করা হলো।

## ১. ব্যাকএন্ডে কী কী থাকা প্রয়োজন এবং সেগুলো কোথায় আছে?

## ২. ব্যাকএন্ডের ৮টি প্রধান সিস্টেমের কাজের বিবরণ

### ১. অথেনটিকেশন ও ভিআইপি আইডেন্টিটি সিস্টেম (`AuthController.php` & `User.php`)
* **পাসকি ও বায়োমেট্রিক সাপোর্ট**: অ্যাপলের ফেস আইডি বা পাসকি টোকেন দিয়ে পাসওয়ার্ড ছাড়াই সিকিউর এনক্লেভের মাধ্যমে ১-ট্যাপে ক্লায়েন্ট অথেনটিকেশন।
* **VIP Noir Tier ইঞ্জিন**: ইউজারের কেনাকাটার ভিত্তিতে লয়্যালটি পয়েন্ট স্বয়ংক্রিয়ভাবে বাড়ে (প্রতি $১ খরচে ১ পয়েন্ট) এবং নির্দিষ্ট থ্রেশহোল্ড অতিক্রম করলে গোল্ড থেকে নয়্যার (Noir) টিয়ারে উন্নীত হয়।
* **ডেডিকেটেড কনসিয়ার্জ অ্যাসাইনমেন্ট**: ভিআইপি ক্লায়েন্টদের জন্য সার্বক্ষণিক ব্যক্তিগত ফ্যাশন উপদেষ্টা (যেমন: Sophie L.) যুক্ত থাকে।

### ২. প্রোডাক্ট ক্যাটালগ ও ক্রাফটম্যানশিপ ইঞ্জিন (`ProductController.php` & `Product.php`)
* **`cursorPaginate()` আর্কিটেকচার**: সাধারণ `OFFSET` পেজিনেশনের পরিবর্তে পয়েন্টার-ভিত্তিক কুয়েরি ব্যবহার করা হয়। ফলে লাখ লাখ প্রোডাক্ট থাকলেও মোবাইলে ইনফিনিট স্ক্রলিং করার সময় $O(1)$ স্পিড বজায় থাকে এবং কোনো ডুপ্লিকেট আইটেম আসে না।
* **PDP স্টোরিটেলিং মেটাডাটা**: প্রোডাক্ট ডিটেইল পেইজে শুধু সাধারণ দাম বা ছবি নয়, বরং ৪টি মূল ক্রাফটম্যানশিপ হটস্পট (NFC Digital Twin, Horsehair Lapel, Watch Reveal, Biella Super 130s) ব্যাকএন্ড থেকে ডাইনামিকালি লোড হয়।
* **ইনভেন্টরি ভ্যারিয়েন্ট ম্যানেজমেন্ট**: প্রতিটি সাইজ (EU 36 থেকে EU 44) এবং রঙের জন্য পৃথক স্টক ও রিজার্ভেশন কাউন্টার থাকে।

### ৩. শপিং ব্যাগ ও প্রমো ইঞ্জিন (`CartController.php` & `Cart.php`)
* **গেস্ট ও লগইন ইউজার কার্ট সিঙ্ক**: গেস্ট ইউজার ব্রাউজ করার সময় `X-Cart-Session` টোকেন দিয়ে কার্ট সংরক্ষণ করা হয়। ইউজার লগইন করার সাথে সাথে তার একাউন্টে কার্ট অটোমেটিক সিঙ্ক হয়ে যায়।
* **রিয়েল-টাইম ডিসকাউন্ট ক্যালকুলেশন**: কুপন কোড (যেমন: `WELCOME15` দিয়ে -$৪৫ অথবা `AURA20` দিয়ে ২০% ছাড়) প্রয়োগ এবং $১৫০ এর বেশি অর্ডারে ফ্রি এক্সপ্রেস শিপিং প্রগ্রেস বার ট্র্যাকিং।

### ৪. অর্ডার ও চেকআউট প্রসেসিং (`CheckoutController.php` & `Order.php`)
* **অ্যাটমিক ডাটাবেজ ট্রানজেকশন (`DB::transaction`)**: চেকআউটের সময় স্টক ভ্যালিডেশন, ট্যাক্স ক্যালকুলেশন, কার্ট খালি করা এবং অর্ডার রেকর্ড তৈরি একক ট্রানজেকশনে সম্পন্ন হয়। এতে নেটওয়ার্ক ড্রপ হলেও ডেটার কোনো অমিল হয় না।
* **প্রোডাকশন লাইফসাইকেল ট্র্যাকিং**: অর্ডারের স্ট্যাটাস ধাপে ধাপে আপডেট হয়:
  `order_received` $\rightarrow$ `cnc_laser_cutting` $\rightarrow$ `artisan_hand_basting` $\rightarrow$ `vacuum_steam_pressing` $\rightarrow$ `final_qc_ultrasonic` $\rightarrow$ `hermetic_cedar_bagging` $\rightarrow$ `dispatched_fleet` $\rightarrow$ `delivered`.

### ৫. ইন-হোম ডোরস্টেপ ট্রাই-অন সিস্টেম (`TryOnController.php` & `TryOnBooking.php`)
* **হোম ট্রাই-অন শিডিউলিং**: ক্লায়েন্টরা তাদের সুবিধাজনক সময়ে ডোরস্টেপ ফিটিং বুক করতে পারে।
* **ফ্লিট ও বাফার ডিস্ট্রিবিউশন**: কুরিয়ার ভ্যান (Mercedes eVito #07) ক্লায়েন্টের পছন্দের সাইজের পাশাপাশি আগে-পরের ২টি বাফার সাইজ নিয়ে ডোরস্টেপে হাজির হয়।
* **কিপ-রেট ও গ্র্যাচুইটি অডিটিং**: ফিটিং শেষে ক্লায়েন্ট কোন সাইজটি রাখল এবং কুরিয়ারকে কত টিপস প্রদান করল তা রেকর্ড করা হয়।

### ৬. সেলফ-সার্ভিস রিটার্ন ও ডিজিটাল পাস (`ReturnController.php` & `ReturnRequest.php`)
* **পেপারলেস রিটার্ন**: কোনো বক্স বা প্রিন্ট করা লেবেল ছাড়া ড্রপ-অফ কিউআর পাসের মাধ্যমে সহজে সোলো বা স্টুডিও হাবে রিটার্ন নেওয়া হয়।
* **ইনস্ট্যান্ট বোনাস স্টোর ক্রেডিট**: কার্ড রিফান্ডের পাশাপাশি ১০% বোনাস স্টোর ক্রেডিটের অপশন প্রদান করা হয়।

### ৭. অ্যাটেলিয়ার ওয়ার্কশপ ও কিউসি ওয়ার্কস্টেশন (`AtelierOpsController.php`)
* **স্টেজ ০৫ ফাইনাল কিউসি সাইন-অফ**: অপটিক্যাল স্পেক ভেরিফিকেশন এবং ৩৫ কিলোহার্টজ আল্ট্রাসনিক ওয়েল্টারের মাধ্যমে এনএফসি সিল অ্যাক্টিভেশন।
* **ডোরস্টেপ এনএফসি চ্যালেঞ্জ-রেসপন্স**: NTAG424 DNA ক্রিপ্টোগ্রাফিক চিপ মিউচুয়াল অথেনটিকেশন করে টেম্পার-প্রুফ মাইক্রো-ল্যাচ আনলক করা।
* **ফ্লিট ডিসপ্যাচ কমান্ড**: রিয়েল-টাইম জিপিএস ও ভ্যান ব্যাটারি মনিটরিং।

### ৮. ইমেজ অপ্টিমাইজেশন সার্ভিস (`ImageOptimizationService.php`)
* Intervention Image v3 ব্যবহার করে যেকোনো আপলোড করা ছবিকে ব্যাকগ্রাউন্ডে স্বয়ংক্রিয়ভাবে ৩টি সাইজে (Thumb 300px, Catalog 600px, Hero 1200px) রিসাইজ করে ৮০% কোয়ালিটিতে আধুনিক **WebP** ফরম্যাটে রূপান্তর করে।

## ৩. সম্পূর্ণ API এন্ডপয়েন্ট তালিকা (v1)

| মেথড | API এন্ডপয়েন্ট | বিবরণ |
| :--- | :--- | :--- |
| **POST** | `/api/v1/auth/login` | ক্লায়েন্ট পাসওয়ার্ড অথবা পাসকি লগইন |
| **POST** | `/api/v1/auth/register` | নতুন ক্লায়েন্ট অ্যাকাউন্ট তৈরি |
| **GET** | `/api/v1/auth/profile` | ভিআইপি টিয়ার, লয়্যালটি পয়েন্ট ও প্রোফাইল ডেটা |
| **GET** | `/api/v1/products` | `cursorPaginate()` ভিত্তিক ইনফিনিট স্ক্রল প্রোডাক্ট ফিড |
| **GET** | `/api/v1/products/{idOrSlug}` | পিডিপি (PDP) বিস্তারিত ও ক্রাফটম্যানশিপ হটস্পট |
| **GET** | `/api/v1/categories` | সমস্ত সক্রিয় ক্যাটাগরি ও প্রোডাক্ট সংখ্যা |
| **GET** | `/api/v1/cart` | শপিং ব্যাগের বর্তমান অবস্থা ও সাবটোটাল |
| **POST** | `/api/v1/cart/items` | নির্দিষ্ট সাইজ ও কালারসহ ব্যাগ-এ আইটেম যোগ |
| **PATCH**| `/api/v1/cart/items/{id}` | ব্যাগের আইটেমের পরিমাণ পরিবর্তন |
| **DELETE**| `/api/v1/cart/items/{id}` | ব্যাগ থেকে আইটেম মুছে ফেলা |
| **POST** | `/api/v1/cart/coupon` | প্রোমোকোড অ্যাপ্লাই (`AURA20`, `WELCOME15`) |

## ৪. React ফ্রন্টএন্ডের সাথে Laravel ব্যাকএন্ড কীভাবে কানেক্ট করবেন?

ফ্রন্টএন্ডে ইতিমধ্যে তৈরি করা সার্ভিস ফাইলটি (`src/data/mockProducts.js`) সরাসরি এই Laravel এন্ডপয়েন্টগুলোর সাথে যুক্ত হতে প্রস্তুত।

### ১. পরিবেশ পরিবর্তনশীল (`.env`) সেটআপ
আপনার রিয়্যাক্ট অ্যাপের রুট ফোল্ডারে `.env` ফাইলে Laravel API এর ইউআরএল দিন:
```env
VITE_API_BASE_URL=http://localhost:8000/api/v1
```

### ২. Axios বা Fetch দিয়ে ডেটা আনা
```javascript
// src/services/apiClient.js
const API_BASE = import.meta.env.VITE_API_BASE_URL || 'http://localhost:8000/api/v1';

export async function fetchCatalogProducts(cursor = null, category = null) {
  const url = new URL(`${API_BASE}/products`);
  if (cursor) url.searchParams.append('cursor', cursor);
  if (category && category !== 'All Pieces') url.searchParams.append('category', category);

  const response = await fetch(url.toString(), {
    headers: {
      'Accept': 'application/json',
      'X-Cart-Session': localStorage.getItem('aura_cart_session') || ''
    }
  });
  return await response.json();
}
```

## ৫. সংক্ষেপে সারাংশ

আপনার অ্যাপ্লিকেশনের ব্যাকএন্ড সম্পূর্ণভাবে সাজানো হয়েছে:
1. **ডাটাবেজ আর্কিটেকচার**: ৬টি মাইগ্রেশন ফাইল দিয়ে ইউজার, প্রোডাক্ট, ভ্যারিয়েন্ট, কার্ট, অর্ডার, ট্রাই-অন এবং রিটার্ন টেবিল প্রস্তুত।
2. **মডেল লেয়ার**: ১০টি ইলোকয়েন্ট মডেল দিয়ে তাদের মধ্যকার রিলেশনশিপ ও হিসাব-নিকাশ সম্পন্ন।
3. **কন্ট্রোলার লেয়ার**: ৮টি ডেডিকেটেড এপিআই কন্ট্রোলার দিয়ে ফ্রন্টএন্ডের প্রতিটি পেজ ও বাটনের ব্যাকএন্ড লজিক বাস্তবায়িত।
4. **রাউটিং**: `routes/api.php` ফাইলে সমস্ত এন্ডপয়েন্ট সুবিন্যস্ত।
5. **ইমেজ ইঞ্জিন**: `ImageOptimizationService.php` দিয়ে স্বয়ংক্রিয় WebP কনভার্সন প্রস্তুত।
